# FinchGram Logo

[English](README.md)

品牌色：靛蓝 #4a5fc1

## svg/
- FinchGram-icon.svg：App 图标，靛蓝圆角方形底，白色鸟（主版本）
- FinchGram-icon-dark.svg / -light.svg / -mono.svg：深色底、浅色底、单色
- FinchGram-icon-16.svg：16–20px 专用，只留剪影（去掉眼睛和翅膀缝）
- FinchGram-mark.svg / -black.svg / -white.svg：单独的鸟形标记，可放在文字旁
- FinchGram-mark-16.svg：小尺寸剪影标记

## png/
- FinchGram-icon-16 … 1024.png：App 图标各尺寸（16px 用剪影版）
- FinchGram-mark-*-1024.png：透明底标记

## 使用规则
- 不要改成圆形底，不要用 Telegram 官方蓝（API 条款第 2.4 条：不得使用 Telegram 官方 logo）
- 20px 以下一律用 -16 剪影版
- 标记四周至少留出鸟身高度 1/4 的空白
- 应用名写作 FinchGram（F、G 大写），不含 "Telegram"

矢量轮廓由原稿 PNG 描出，正式发布前建议在矢量软件里修一遍曲线。
